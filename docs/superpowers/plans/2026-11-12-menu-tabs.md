# Menu à onglets — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter une barre d'onglets en bas de la PWA avec trois onglets : « Animaux », « À venir », « Compte ».

**Architecture:** Un groupe de routes `(app)/(tabs)` porte un `<Tabs>` d'expo-router. Il contient les trois écrans racines. La pile `(app)/_layout.tsx` existante reste la racine : `(tabs)` et `animals/*` y sont frères. Les écrans de détail (fiche animal, événement, formulaires) s'empilent donc **par-dessus** les onglets, et la barre y est masquée (option A validée).

**Tech Stack:** Expo 56 (web uniquement), expo-router `Tabs` (déjà installé, aucune dépendance ajoutée), NativeWind, Jest + @testing-library/react-native.

**Spec:** les décisions prises le 2026-11-12 avec Yassine (pas de document séparé) :
- trois onglets : Mes animaux, À venir (échéances via `api.listUpcomingEvents`), Compte/Réglages ;
- barre en bas ;
- barre masquée sur les écrans de détail ;
- `Tabs` JS d'expo-router.

## Global Constraints

- Aucune nouvelle dépendance npm.
- Libellés des onglets : `Animaux`, `À venir`, `Compte`.
- Textes en français, accessibilité : chaque onglet a un `tabBarAccessibilityLabel` égal à son libellé.
- Couleurs uniquement via `Colors[scheme]` (`@/constants/theme`) : actif `text`, inactif `textTertiary`, fond `surface`, bordure `border`. Le mode sombre doit fonctionner.
- La colonne de 480 px de `src/app/_layout.tsx` ne change pas ; la barre vit dedans.
- Aucune modification de l'API.
- Icônes : seulement via `<Icon>` (`@/components/ui`), en ajoutant les noms manquants dans `icon.tsx`.

## Review Focus

1. **Échéance dépassée ou du jour** : `GET /health-events/upcoming` filtre `nextDueDate >= now`. Les échéances en retard, et celles d'aujourd'hui (stockées à minuit), **n'apparaissent pas**. On l'accepte pour ce plan (pas de changement d'API). L'écran doit simplement ne pas planter, et ses tests ne doivent pas promettre de retards. Badge `late` impossible ici : on ne l'affiche que via `deadlineState`, sans cas particulier.
2. **Ouverture directe de `/animals`** (ancien lien, PWA en favori) : doit mener à l'onglet Animaux **avec** la barre, pas à une liste sans barre. Test dans la tâche 1.
3. **Retour depuis une fiche** : après `router.push('/animals/1')` puis retour, on revient sur l'onglet d'origine avec la barre. Vérification manuelle dans la tâche 3.
4. **Rechargement des données** : passer d'un onglet à l'autre puis revenir doit recharger (`useFocusEffect`), pas afficher une liste figée. Test dans la tâche 2.
5. **iPhone en PWA installée** : la barre ne doit pas passer sous l'indicateur d'accueil (safe area bas). `Tabs` gère l'inset bas ; à vérifier en 375×812 dans la tâche 3.
